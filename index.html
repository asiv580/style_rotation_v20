1.2 均值族 —— 趋势跟随 · 全仓二态（创业板腿）

仓位只有两种状态：100% 成长 或 100% 红利，无中间档。切换由六个组件共同决定，其中 ④⑤ 是两条「防甩出 / 防追高」的锁。

组件参数作用与触发条件
① MA20 滞回带20 日均值 ±1.5%基本趋势开关：比值 上穿 MA20×1.015 → 买成长；下穿 MA20×0.985 → 卖成长。±1.5% 带用于滤除均线附近的反复穿越（消抖）。
② 低位钳制比值 < 0.52（≈P4.5%）成长相对红利处于历史 极低位 → 强制买成长，不等均线信号（防「越跌越不敢买」）。
③ 高位钳制比值 > 1.20（≈P97.1%）成长 极贵 → 强制卖成长，不等均线信号（防「越涨越加仓」）。
④ L 首卖门控门控线 0.546 = 0.52×1.05由 ② 低位钳制买入后加锁：此后 首次卖出必须且仅在比值 > 0.546 时才执行；比值 ≤0.546 时的均线下穿 一律否决；首卖执行后解锁。作用：防止在成长已被打得极便宜的时点被均线噪声甩出（属信号层机制，与 2.0 止损层无关）。
⑤ H 解锁线解锁线 1.152 = 1.20×0.96由 ③ 高位钳制卖出后加锁：比值仍 > 1.152 时 禁止回补（不在刚卖飞的高位买回来）；跌破 1.152 解锁。
⑥ F1 拥挤禁买成长自 250 日高回撤 < −20% 且 比值 expanding 分位 > 70%熊市急跌期「成长暴跌但比值仍不低」的 假低点 → 否决该买点（② 低位钳制与 ① 带内买点均适用）。
⚠️ F1 只否决"买入成长"，不触发卖出、也不影响已持有的成长仓——它是"进门检查"而非"清场检查"：持仓的退出只由 ① 带内卖点 / ③ 高位钳制 / ④ L 首卖门控决定。同样，它从不干预"持/买红利"方向。

1.0 实测：CAGR 34.84%（毛）· 终值 106.69x · MaxDD 39.68% · 卡玛 0.90 · 换手 122 次。

1.4 分位族 —— 分位滞回 · 四档阶梯

同一比值、同一窗口，但用 expanding 分位（而非均线）定档，仓位为四档加权（成长:红利）：

档位权重构成触发条件
1:0 全成长100% 成长 / 0% 红利比值分位 ≤5% 且 比值自 250 日谷值回升 ≥8% → 一步满仓（底部是尖的，分批买会踏空）
3:175% 成长 / 25% 红利由 1:0：分位 ≥70% 且 比值自 250 日峰值回撤 ≥8% → 卖出 1/4。（初始档位亦为 3:1）
1:325% 成长 / 75% 红利由 3:1：分位 ≥97%，无需确认，每轮仅一次 → 再卖 1/2。
由 1:0：分位 ≥97% 直接跳至此档（满仓出口闸门，不等确认）。
0:1 全红利0% 成长 / 100% 红利分位 ≥97% 且 自 250 日峰值回撤 ≥8% → 清掉剩余 1/4。

设计意图：卖出分三段递减（1/4 → 1/2 → 1/4），并在最高位保留一个「无需确认」的强制减半步，避免「卖半后高位钝化、随后缓跌而错过清仓」；买入只有一步。分位按 expanding 口径（截至 T 日的全部历史）计算，无前视。
1.0 实测：CAGR 20.6% · 终值 18.64x · 卡玛 0.52 · 调仓 10 次。

1.5 从 1.0 到 2.0 的增量

2.0 = 1.0 均值族信号（上表 ①~⑥ 全部不动）+ 组合级绝对止损层；分位族与科创50 对照腿均保持 1.0 原样。
止损层规则：策略净值自历史峰值回撤 ≥15% → 全部赎回、100% 持现金；恢复须 同时 满足「原轮动信号 = 持成长」且「创业板指自离场期最低点反弹 ≥3%」（最低点每日刷新）；恢复后峰值重置为恢复时净值，每轮独立计 15%。
止损层的完整参数依据、逐次触发/恢复明细（含最新一次若仍在离场中）与稳健性检验，见后文对应章节。

七、方法论与假设

  • 标的与口径：成长腿 = 创业板指（399006）/ 防守腿 = 标普中国A股大盘红利低波50（SPCLLHCP.SPI，价格指数、非全收益）。比值 = 成长收盘 ÷ 红利收盘。两指数价格口径、未计分红再投资（两腿对称公平）。评估窗口 2010-07-15 ~ 2026-09-29（3938 交易日，随数据推进动态）。
  • 2.0 基线相对 1.0 的唯一变更：在均值族信号之上叠加组合级绝对止损/恢复层——策略净值自历史峰值回撤 ≥15% 时全部赎回、100% 持现金；恢复须同时满足 ① 原轮动信号 = 持成长 ② 创业板指自「离场期最低点」反弹 ≥3%（最低点每日刷新 min(昨日基准, 当日创业板指收盘)）；恢复后峰值重置为恢复时净值，每轮独立计 15%。分位族规则与全部参数不变。完整的 1.0 两族规则、参数与逐条触发条件见第一章「1.0 基线策略说明」。
  • 止损层锚点非对称（关键设计）：触发锚 = 策略净值，恢复锚 = 创业板指。离场后持现金，净值冻结为水平直线，任何「净值型」恢复条件都会永久死锁；恢复条件必须挂在会动的价格上。恢复条件中的「原信号=持成长」不是第二重确认，而是锚与标的匹配器：保证用创业板指确认的反弹、恢复后买的也是创业板资产（实测去掉后恢复 14 次中 7 次误买红利，恢复后 20 日平均 −2.86%，MaxDD 由 23.6% 恶化至 36.5%）。
  • 参数选型依据（生产引擎复核）：D=15% 在 D∈[8%,20%] × X∈[2%,6%] 的 25 格邻域内卡玛极差 0.26（平台），D=8% 极差 0.62（尖峰）且抗滑点差、假警报率 54%、恢复后 20 日内再止损 7 次；D=15% 止损有效率 67%、恢复后再触发 0 次。D=15%/X=3% 位于平台中心而非孤立最优。
  • 无前视：全部信号仅用 T 日及以前数据——均值族 MA20/钳制 expanding 分位/250 日回撤、止损层的净值峰值与创业板指离场低点，均截至 T 日收盘；T 日收盘定信号、T+1 生效。
  • 两族规则差异：均值族 = 趋势跟随·全仓二态 + 2.0 止损层；分位族 = 分位滞回·四档阶梯。两族完整规则、参数与逐条触发条件见第一章「1.0 基线策略说明」——其中 1.0 = 该章全部内容；2.0 = 仅均值族叠加止损层，分位族与科创50 对照腿保持 1.0 原样。
  • F1（均值族）：成长自 250 日高回撤 < −20% 且比值 expanding 分位 > 70% → 否决低位钳制/带内买点。
  • 交易成本：主表为毛口径（与 1.0 基线报告一致）。均值族 2.0 换手 138 次（信号 124 + 止损层 14）/16.1 年；费后敏感性见第六章，万1.8 实盘档 CAGR 34.82%。
    ⚠️ 口径防混淆（重要）：本报告中 1.0 基线（无止损）的毛口径 CAGR 34.84% 与 2.0 含止损后的费后万1.8 档 CAGR 34.82% 数值巧合相同，但含义完全不同——前者未计交易费用、后者已计交易成本；且两者相对主口径（2.0 毛 35.20%）的偏离方向相反。引用任何 CAGR 时请先确认所属口径。
  • 科创50 对照腿：信号与 1.0 基线一致（出1%/回补0%带 + 钳 0.217/0.577 + L 解锁 0.228 + F1），换手 105；2.0 未对其启用止损层，交叉验证结果见第六章。
  • 已知局限：① 止损层样本内触发 13 次（截至 2026-09-29，其中 1 次仍在离场中、尚未产生空仓交易日），已完成段里 2015/2016 两段合计占空仓 111/214 日（52%），结论对这两段权重较高；② 红利低波50 价格指数不含分红，长期低估防守腿实际收益；③ 科创50 腿窗口仅 6.5 年，无法验证 2015 型情形；④ 全部参数为先验设定或平台中心选点，未做带外优化。

八、结论要点

  • 收益端：止损层不但不损失收益，反而小幅增益。均值族 2.0 CAGR 35.20%（111.28x，毛口径）vs 1.0 34.84%（106.69x，毛口径），+0.37pp——本节两数均为毛口径（未计费用），可直接对比；实盘费后万1.8 档见第六章（2.0 为 34.82%），与 1.0 毛口径数值巧合相同、切勿混用。机制不是"躲开跌幅"，而是反弹确认后再入场的位置常优于原信号在下跌中途的买点（12 次恢复后 20 日创业板指平均 +8.79%，8/12 为正）。
  • 风险端：最大回撤由 39.68% 降至 23.60%（−16.1pp），卡玛 0.90 → 1.53（+70%）。回撤重心从 2015-06-12→08-25 的 51 日急跌，转移为 2018-03→10 的温和区间。这一改善来自"空仓"而非"换腿"。
  • 止损层是定向优化，不是普适规则。同参数在科创50 对照腿上收益倒退（36.92%→33.58%），因为该腿样本不含 2015 型红利崩盘。创业板腿的增益有明确机制支撑（轮动信号对"红利阴跌"结构性无感——成长跌得更快会先把信号切走，红利阴跌时比值反而上行、信号叫你继续拿），但样本外有效性仍取决于同类事件重演。
  • 两族定位不变：均值族 2.0 = 趋势跟随·全仓二态 + 绝对止损，主吃主升浪浓度且回撤已被压制；分位族 = 分位滞回·四档阶梯，换手低、防守段保护。2.0 之后均值族在收益与回撤两端均优于分位族（35.20% vs 20.6%，MaxDD 23.60% vs 39.68%）。
  • 当前状态（2026-09-29）：离场中（持现金）。比值 0.864（分位 60%）· 均值信号 红利 · 净值自峰值 -15.64% · 利差 +1.11pp（利差分位 92%）。止损层优先于信号层 → 清仓后 100% 持现金；信号层的「持红利」不执行。恢复须同时满足 ① 信号=持成长 ② 创业板指自离场最低点 3139.82 反弹 ≥3%（当前 +0.09%）
  • 已知代价：① 空仓 5.5%（215 日），若下一波由红利领涨而信号仍指向红利，策略会一直空仓错过——这是恢复条件「原信号=持成长」的固有代价；② 换手由 122 增至 138 次；③ 214 日空仓中 111 日来自 2015/2016 两段。
